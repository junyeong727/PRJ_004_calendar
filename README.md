# PRJ_004_calendar
PC와 모바일용 달력

제작 배경(背景)
PC바탕화면에 위젯 형식으로 된 프로그램이 많이 나와있는데 달력은 없는 것 같아서 만들어보고 싶어졌음
デスクトップの画面上にカレンダーのアプリみたいなものがなさそうなので、作ってみたくなった

사양서(仕様書)
- PC판 프로그램
  1. PC판 프로그램을 최초 실행(설치) 후에는 시작 프로그램으로서 자동 실행되도록 한다
  2. 달력이 기본 프로그램이므로 현재 날짜를 부각시키는 기능이 필요
  3. 이전달(preMonth)・다음달(nextMonth) 기능, Search기능(해당년월일을 입력하는 것으로 이동)
  4. 달력 기능에 메모 기능과 알림기능을 추가
  5. PC해상도에 따라 설정이 가능하도록 하는 기능과 커스터마이즈가 가능하도록 하는 기능을 추가

- 모바일 어플리케이션
  1. 위젯기능
  2. PC판의 2, 3, 4을 작성
 
- 공통
  1. 언어설정
  2. 국가 선택(국가휴무일 등을 위해) - 초기버전에서는 한국만 이후 국가 추가
